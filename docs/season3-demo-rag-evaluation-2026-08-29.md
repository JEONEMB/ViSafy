## 3. 확인된 한계 — 비한국어 답변의 수치 손실

숫자·Visa 코드 무결성 0.77은 **검색이 아니라 답변 생성 단계**의 문제이며, 실패 11건은 전부 비한국어다.

| 언어 | 무결성 실패 |
| --- | ---: |
| 한국어 | 0건 |
| 영어 | 3건 |
| 베트남어·중국어·일본어·태국어 | 각 2건 |

원인은 [`answer_builder.py`](../ai-service/app/guardrail/answer_builder.py)의 `_localized_excerpt`다.
한국어는 공식 원문을 그대로 인용하지만, 비한국어는 원문의 한국어 키워드를 감지해 **미리 정의된 문장으로 대체**한다.
이 과정에서 `E-7`, `E-9` 같은 체류자격 코드와 금액·기간 숫자가 답변에서 사라진다.

- 안전 측면에서는 문제가 없다. 없는 숫자를 만들어내지 않고, 누락시킬 뿐이다.
- 다만 외국인 대상 서비스에서 **비한국어 사용자가 한국어 사용자보다 덜 구체적인 답변을 받는다**는 점은 개선 대상이다.
- 현재 OpenAI 설명 계층은 숫자·Visa 코드 무결성 검증을 통과한 경우에만 사용되므로, 이 한계는 LLM 장애 시 폴백되는 템플릿 경로에 한정된다.

수치를 숨기지 않고 그대로 보관한다. Top-K 검색 품질과 다국어 답변 표현 품질은 서로 다른 완료조건이다.
